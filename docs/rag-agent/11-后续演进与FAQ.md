## 1. 本域内演进

1. 检索增强：多路召回、Rerank、混合检索  
2. 知识形态：OCR、复杂表格、知识图谱融合  
3. 体验：更好的引用跳转、会话内「仅用某文档」过滤  
4. 服务化：独立为 `cacch-ai-rag-service`  
5. 运营：点赞点踩、热问统计、知识质量看板  
6. 性能：检索缓存、FAQ 缓存、批量异步与多副本

## 2. 跨能力域：不要写进本域 backlog

下列需求属于**平台其他能力域**，请到对应目录立项，而不是继续扩写 RAG 对话：

| 需求 | 文档入口 |
| :--- | :--- |
| 无库/角色助手 | [chat-assistant](../chat-assistant/README.md) |
| 工具调用、多步办事 | [agent-orchestration](../agent-orchestration/README.md) |
| 文案/报告/摘要生成 | [content-generation](../content-generation/README.md) |
| 抽取/分类/结构化 | [doc-intelligence](../doc-intelligence/README.md) |
| 共享 LLM/鉴权/观测增强 | [platform](../platform/README.md) |

**组合示例（合法）**：Agent 将「知识库检索」注册为工具 → 编排文档写在 Agent 域，检索实现仍复用本域 Retriever。

## 3. 常见问题

| 问题 | 建议 |
| :--- | :--- |
| 换了 Embedding 后检索全乱 | 维度/模型变更需全量重建 |
| 回答很空泛 | 检查召回是否为空、Prompt 是否允许闲聊 |
| 串库 | 检查检索是否带 `kb_id` |
| 流式前端卡住 | Nginx 是否缓冲 SSE |
| 入库很慢 | 是否误走同步接口；改为 Worker |
| session 答非所问 | 是否绑定了错误 `kb_id` |
| 「还要做生成/Agent」却只在本目录加需求 | 先归类到能力地图，开对应域文档 |

## 4. 术语表

| 术语 | 含义 |
| :--- | :--- |
| AI 平台 | 多能力域共存的工程与产品载体（本仓库） |
| 能力域 | RAG / 助手 / Agent / 生成 / 文档智能等 |
| RAG | 检索增强生成 |
| Chunk | 文档切片 |
| Embedding | 文本向量化 |
| Top-K | 召回前 K 条 |
| Rerank | 对召回结果精排 |
| SSE | 服务端推送流式事件 |
| 固定窗口切片 | 按字符/token 长度+重叠切分 |
| 语义切片 | 按语义边界切分（本 MVP 非默认） |
| ingest_task | 异步入库任务 |
