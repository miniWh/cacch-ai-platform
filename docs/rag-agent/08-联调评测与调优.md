3. 迭代 Prompt，减少幻觉、规范表述  
4. 建立黄金问答集并按下列指标评测  

### 黄金集建议

准备 30～100 条：`question`、`expected_doc_ids` 或 `expected_keywords`、可选参考答案。  
覆盖：事实问答、跨段落综合、应拒答、易混淆问题。

### 指标

| 指标 | 定义 |
| :--- | :--- |
| 检索命中率 | Top-K 是否包含应命中文档/片段 |
| 答案忠实度 | 是否脱离上下文编造 |
| 应拒答正确率 | 无依据时应明确无法回答 |
| 端到端满意度 | 抽检 1～5 分 |

### 实验记录要求

每次只改一个变量（切片 / Top-K / Prompt / Embedding），记录配置、得分、样本 case。
