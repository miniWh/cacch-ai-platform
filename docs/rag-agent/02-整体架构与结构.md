## 1. 核心业务流程（本域）

### 1.1 问答链路

```text
用户提问(+ kb_id, session_id)
  → 鉴权与参数校验
  → 提问向量化
  → 向量库相似度检索（强制 kb_id 过滤）
  →（可选）关键词/稀疏召回 + 重排
  → 拼接 Prompt（系统指令 + 检索上下文 + 历史 + 当前问题）
  → 大模型流式生成
  → SSE 推送 token；结束后推送 citations
  → 落库消息与引用关系
```

### 1.2 入库链路

```text
提交入库请求 → 创建 ingest_task（queued）
  → Worker 拉取任务
  → 加载/清洗 → 切片 → 批量 Embedding
  → 同 doc 先删旧 chunk 再写新向量 + 元数据（版本+1）
  → 任务状态 success/failed
```
