## 2. 表结构要点

> **物理表前缀**：共享库中统一 `cacch_ai_`（如 `cacch_ai_knowledge_base`、`cacch_ai_source_site`），与其它业务表隔离。  
> 应用仅允许对这些 AI 表做增删改；DDL/权限见 `scripts/schema_source_site.sql`、`scripts/grant_cacch_ai_tables.sql`。

## 3. 向量库集合约定

- Collection/表名建议：`kb_chunk_{embedding_dim}` 或按 kb 分集合  
- 字段：`chunk_id`, `kb_id`, `doc_id`, `vector[dim]`, `content`（可选）  
- 度量：默认 **COSINE**（与 Embedding 归一化策略一致）  
- **更换 Embedding 模型或维度 = 全量重建向量，禁止混写**

- [ ] 索引类型与基础参数已记录（如 HNSW/IVF）

## 4. 接口契约

> **前缀约定（已选定）**：本域管理/调试 API 统一使用 `/api/v1/rag/...`，与助手/Agent 等域隔离，平台网关按前缀路由。  
> **对话入口分层**（对齐 [平台 02](../platform/02-应用与能力挂载模型.md)）：
>
> | 调用方 | 路径 | 说明 |
> | :--- | :--- | :--- |
> | **终端用户 / 工作台对话台** | `POST /api/v1/apps/{id}/chat` | **默认入口**；内部按 `app_type` 路由到本域 Manager；`kb` 从 App `bindings` 解析 |
> | **域内管理 / 调试** | `POST /api/v1/rag/chat` | 可显式传 `kb_id`；不作为终端长期唯一入口 |
>
> 下文 §4.2～§4.5 描述**域内**契约；App CRUD / `apps/{id}/chat` / `apps/{id}/config` 以平台 02 为准。

### 4.1 统一响应（非流式）

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

错误：`code != 0`，`message` 为可读原因。

### 4.2 对话（非流式）`POST /api/v1/rag/chat`

> 域内调试/管理用。终端默认应走 `POST /api/v1/apps/{id}/chat`。

请求：
```json
{
  "session_id": "可选，空则新建",
  "kb_id": 1,
  "app_id": "可选；有则校验 bindings 含该 kb",
  "query": "报销流程是什么？",
  "stream": false,
  "top_k": 4
}
```

响应 `data`：
```json
{
  "session_id": "s_xxx",
  "answer": "根据知识库……",
  "citations": [
    {
      "chunk_id": "c_1",
      "doc_id": 12,
      "title": "报销制度.pdf",
      "score": 0.83,
      "snippet": "……报销需先提交……"
    }
  ]
}
```

### 4.3 对话（流式）

`POST /api/v1/rag/chat`（`stream: true`）或 `POST /api/v1/rag/chat/stream`  
`Content-Type: text/event-stream`

```text
event: meta
data: {"session_id":"s_xxx"}

event: token
data: {"text":"根据"}

event: citations
data: {"citations":[...]}

event: done
data: {"finish_reason":"stop"}

event: error
data: {"message":"模型调用失败，请稍后重试"}
```

| 方法 | 路径 | 说明 |
| :--- | :--- | :--- |

| POST | `/api/v1/rag/kb/{kb_id}/documents/upload` | 上传文件 → ingest_task |

### 4.5 站点源（sources）

本域完整版 / 业务需求中的站点清单 API 落在：

| 方法 | 路径 | 说明 |
| :--- | :--- | :--- |
| GET/POST | `/api/v1/rag/kb/{kb_id}/sources` | 站点列表 / 新建 |
| GET/PATCH/DELETE | `/api/v1/rag/kb/{kb_id}/sources/{site_id}` | 详情 / 编辑启停 / 删除 |
| POST | `/api/v1/rag/kb/{kb_id}/sources/probe` | 探活 |
| POST | `/api/v1/rag/kb/{kb_id}/sources/{site_id}/sync` | 触发同步（完整版） |

字段、优先级与「禁止 import 文件灌库」等产品约束见 [requirements/01-网站资料检索与AI问答.md](./requirements/01-网站资料检索与AI问答.md) §6；实现时以该需求为准扩展 OpenAPI。

鉴权（MVP）：请求头 `Authorization: Bearer <API_AUTH_TOKEN>`。
