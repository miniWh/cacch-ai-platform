## 0. 与平台底座的关系

本域依赖平台统一的：LLM Gateway、Embedding、鉴权、配置、异步任务、日志。  
若底座尚未建设，可在本域 MVP 中**先实现一版并预留抽取为 `core` 共享模块**的边界，供助手/Agent/生成等后续复用。

## 1. 技术栈选型

| 层级 | 技术选型 | 说明 |
| :--- | :--- | :--- |
| 开发语言 | Python 3.10+ | 适配 AI 生态组件 |
| Web 框架 | FastAPI + Uvicorn | 异步接口，适配 SSE |
| 大模型 | 通义千问（阿里云百炼）/ OpenAI API 等 | 生成回答；当前默认百炼 |
| Embedding | 同厂商或独立 Embedding API | **维度固定后不可随意更换**；示例默认 `2048`（百炼 `text-embedding-v4`），见 [附录 B](./appendix/B-配置与Compose模板.md) `EMBEDDING_DIM` |
| 向量数据库 | Milvus Standalone / PGVector | 向量 + 元数据检索 |
| 关系型数据库 | MySQL 8.0 / PostgreSQL | 元数据、会话、任务 |
| 文档解析 | Unstructured / PDFPlumber + python-docx | 解析用库；**编排自研** |
| 可选编排辅助 | LangChain 仅作 Loader/Splitter | 禁止业务层被框架强绑定 |
| 网站爬取 | BeautifulSoup4 + Requests / Crawlee | 完整版；遵守 robots 与版权 |
| 任务队列 | Redis + Worker（或 Celery/ARQ） | 异步入库 |
| 前端 | Vue 3 + Element Plus | 对话与知识库管理 |
| 工程管理 | Poetry / PDM | 依赖与虚拟环境 |
| 可选重排 | bge-reranker 等 | 完整版增强，非 MVP 必需 |
| 可选观测 | 结构化日志 + Token 统计 | 可演进 Langfuse |

**决策原则：** 解析/切片可借用成熟库；**对话编排、检索策略、入库流水线自研**。  
LLM/鉴权等与其他 AI 能力域共享，不在本域私有复制。

## 3. 规范前置约定

### 3.1 命名
- **源码根包**：仓库内 Python 包目录为 `app/`（导入形如 `from app.rag...`，与附录 C 一致）
- **发布/分发包名**：PyPI/内部制品可用 `cacch_ai_xxx`（如 `cacch_ai_platform`）；与源码目录名不必相同
- 服务进程名：`cacch-ai-领域-service`（如 `cacch-ai-rag-service`）

### 3.2 代码分层（单向依赖，禁止反向）

```text
common → dao → core → rag → service → manager → web
```

| 层 | 职责 | 可依赖 |
| :--- | :--- | :--- |
| common | 异常、DTO、常量、工具 | 无业务依赖 |
| dao | ORM、仓储、向量库客户端 | common |
| core | LLM / Embedding / Prompt 适配 | common |
| rag | Loader、Splitter、Pipeline、Retriever | common, dao, core |
| service | 单域业务（知识库、会话、任务） | common, dao |
| manager | 跨域编排（对话全链路） | common, dao, core, rag, service |
| web | 路由、鉴权、入参校验 | manager, service, common |

### 3.3 其他
- 数据对象：Model / DTO / Domain Entity 分离，禁止跨层混用
- 接口：统一 RESTful 返回体；对话支持 SSE
