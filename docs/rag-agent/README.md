# AI 智能体（RAG 对话版）文档

从零搭建一套可落地的检索增强（RAG）对话智能体：**多源知识入库 → 语义检索 → 大模型问答 → Web 对话（含引用来源）**。

> 本目录为唯一正式文档（方案 C）。按编号顺序阅读与执行；进度在本文「执行进度总表」与各分册文首同步维护。

## 项目一句话

面向内部知识库的 Web 问答助手：用户提问后，系统检索指定知识库片段，再交由大模型生成可溯源的回答。

## 范围边界

| 本版做（RAG 对话） | 本版不做（见演进） |
| :--- | :--- |
| 文件/网页/库表入库、向量检索、多轮对话、SSE、引用 | 工具调用、多步 Agent、多租户计费、OCR/知识图谱 |

- **MVP**（约 1.5～3 周）：本地文件入库、单库问答、多轮、SSE、引用、会话历史  
- **完整版**（再 +2～4 周）：爬虫、业务库同步、管理页、增量与异步任务、评测调优  

MVP 验收详见 [00-文档说明与MVP范围.md](./00-文档说明与MVP范围.md)。
