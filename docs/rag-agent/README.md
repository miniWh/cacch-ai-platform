# RAG 知识问答（能力域文档）

本目录是 **CACCH AI Platform** 下的能力域之一：**检索增强（RAG）知识问答**。  
平台还有通用助手、Agent 编排、内容生成、文档智能等需求，总览见 [文档中心](../README.md)，勿将本域文档当作整个平台范围。

> 按编号顺序阅读与执行；进度在本文「执行进度总表」与各分册文首同步维护。

## 本域一句话

面向内部知识库的问答能力：用户提问 → 按知识库检索片段 → 大模型生成 **可溯源** 回答（含 Web 对话形态）。

## 在平台中的位置

| 层级 | 内容 |
| :--- | :--- |
| 平台 | 多 AI 能力共存，共享 LLM/鉴权/任务/观测 |
| **本域** | 知识入库、向量检索、RAG 对话、引用 |
| 非本域 | 无库助手、工具调用 Agent、纯生成、结构化抽取等 |

本域完整版实现时，文件存储、ACL、混合检索须符合 [平台 04](../platform/04-数据面约定-ACL与对象存储.md)；发布与黄金集门禁对齐 [平台 06](../platform/06-可观测评测与反馈门禁.md)。

## 本域范围

| 本域做 | 本域不做（见其他能力域 / 演进） |
| :--- | :--- |
| 文件/网页/库表入库、向量检索、多轮 RAG 对话、SSE、引用 | 通用无库闲聊、工具调用多步 Agent、纯文案生成中台、字段抽取主路径 |

- **MVP**（约 1.5～3 周）：本地文件入库、单库问答、多轮、SSE、引用、会话历史  
- **完整版**（再 +2～4 周）：爬虫、业务库同步、管理页、增量与异步任务、评测调优  

MVP 验收详见 [00-文档说明与MVP范围.md](./00-文档说明与MVP范围.md)。

## 仓库与命名

- 仓库：`cacch-ai-platform`（平台仓）  
- 本域工程/包：可落在平台内模块，或独立 `cacch-ai-rag-service`  
- 源码根包：`app/`；发布包名：`cacch_ai_xxx`；本域 API 前缀：`/api/v1/rag/...`（终端对话走 `/api/v1/apps/{id}/chat`）  
- **复用**：LLM Gateway、鉴权、配置、任务队列走平台共享约定，本域只实现检索与知识编排差异

```text
（平台）00～01 底座 → 02～06 治理约定（可与业务并行）
     → 本域 00～03 对齐
     → 04 基础工程 → 05 入库 → 06 RAG 核心 → 07 Web
     → 08 联调评测 → 09 部署 → 10 安全检查
附录 B/C 随 04～06 对照使用；附录 A 全程勾选。
```

若需求实为助手 / Agent / 生成 / 抽取，请改走对应能力域，勿强行塞进本目录。
