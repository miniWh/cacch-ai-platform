# 通用对话助手（规划）

> **文档状态**：📋 规划中  
> **能力归类**：无强依赖私有知识库的多轮对话、角色助手、系统指令场景  
> **依赖底座**：[平台共享基础](../platform/01-共享基础能力.md)

## 定位

提供稳定的多轮对话能力：**不一定走向量检索**。可与 RAG 共用会话模型与 LLM Gateway，但产品形态独立（例如「办公助手」vs「制度问答」）。

## 典型需求

- 角色设定 / 系统 Prompt 可配置  
- 多轮上下文与摘要压缩  
- 流式输出、会话历史  
- （可选）轻度工具：天气、日历等简单 API  

## 与 RAG 的边界

| 助手 | RAG 知识问答 |
| :--- | :--- |
| 可不绑 `kb_id` | 强制知识库隔离与引用 |
| 允许一定通用知识回答 | 强调「仅依据检索上下文」 |
| Prompt/角色是核心资产 | 知识库质量是核心资产 |
