# 文档智能（规划）

> **文档状态**：📋 规划中  
> **能力归类**：抽取、分类、比对、结构化输出  
> **依赖底座**：[平台共享基础](../platform/01-共享基础能力.md)；解析能力可与 RAG 共享

## 定位

把非结构化文档变成 **字段、标签、比对结论、结构化 JSON**，服务业务系统集成，而不是（或不只是）给人看的对话回答。

## 典型需求

- 合同/表单关键字段抽取  
- 票据/邮件分类路由  
- 两版文档差异说明  
- 固定 Schema 的结构化输出（JSON Mode / 约束解码）  

## 与 RAG 的边界

| 文档智能 | RAG 知识问答 |
| :--- | :--- |
| 输出偏结构化、可进业务库 | 输出偏自然语言回答 |
| 评测看字段准确率 | 评测看召回与忠实度 |
| 可与 RAG 共享 Loader/解析 | 额外需要向量库与对话编排 |
