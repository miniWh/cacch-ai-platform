# 内容生成（规划）

> **文档状态**：📋 规划中  
> **能力归类**：文案、报告、摘要、改写等生成向场景  
> **依赖底座**：[平台共享基础](../platform/01-共享基础能力.md)

## 定位

面向「产出长文本/结构化文稿」的业务，强调 **模板、批处理、风格约束与人工审校**，而不是开放式知识问答。

## 典型需求

- 周报/方案/邮件草稿生成  
- 会议纪要摘要、多文档综述  
- 风格改写、多语言翻译  
- 批量异步生成任务与结果下载  

## 与 RAG 的边界

| 内容生成 | RAG 知识问答 |
| :--- | :--- |
| 输入多为提纲/素材/上传稿 | 输入多为用户问题 |
| 可选用检索作素材增强 | 检索是主路径 |
| 关注格式模板与审校流 | 关注引用与拒答 |
